
# ApexPlanet Internship - Task 3

# Data Visualization & Dashboarding using Python and Power BI

## 📌 Project Overview

This project was completed as part of my Data Analytics Internship at ApexPlanet Software Pvt. Ltd.

The objective of this task is to explore and visualize data using Python visualization libraries and build an interactive dashboard for better business insights.

The project uses the Titanic dataset to analyze passenger information, survival patterns, age distribution, gender distribution, passenger class, and other important relationships through different types of charts and dashboards.

---

# 🎯 Objectives

- Understand the basics of data visualization.
- Create meaningful charts using Python.
- Learn advanced visualization techniques.
- Build an interactive dashboard.
- Present data in an easy-to-understand format.

---

# 📂 Dataset

**Dataset Name:** Titanic Dataset

The dataset contains information such as:

- Passenger ID

- Age

- Fare

- Survival Status
